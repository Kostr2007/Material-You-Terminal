# План: центрирование и анимация карточки

1. Определить фактическую высоту текстовой сводки по видимым символам, учитывая
   ANSI-цвета и горизонтальное позиционирование fastfetch.
2. Выровнять вертикальные центры изображения и сводки без уменьшения снежинки.
   Добавить отдельную опцию центрирования всей композиции по ширине терминала.
3. Встроить единую заставку в существующие 1400 мс: заголовок, линия-разделитель,
   каскад строк, заполнение индикаторов и появление цветовых точек.
4. Сохранить настоящие текстовые символы, исходные значения и точные цвета после
   заставки. После появления промпта только kitty проигрывает графический цикл.
5. Добавить студию полной композиции и проверки центров, конечного кадра,
   сохранности текста, отключения эффектов, сигналов и ввода команд.
6. Проверить тёмный/светлый варианты, настоящее окно kitty, Nix-пакет и сборку
   NixOS. Отправить проверенные изменения в GitHub и обновить только нужный input.
